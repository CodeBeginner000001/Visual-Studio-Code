> Data loss doesn't occur for every type of conversion and the risk depends on what type of conversion is done and in which direction
 * Widening Conversion : A value is converted to a datatype that can hold a larger range of values or high precision. i.e., -> from small range datatype to a large range datatype
   -> Converting an int to a double is safe as double can store all the integer values and has high precision
 * Narrowing Conversion :  A value is converted to a datatype that can hold or has smaller range or lower precision than the original one. 
   -> In this case we have data loss. The values are truncated to store the value in smaller range datatype.
   -> For Eg: converting a float to an int will truncate the decimal part lossing precision in the data.
 * Conversion between Signed and UnSigned Type : converting in between these two type can cause data loss and unexpected behaviour.
   -> converting a signed integer to an unsigned integer may result in very large positive number.
